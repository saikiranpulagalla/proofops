## RC5 safety boundary
New first executions cross human authorization and provider-attempt creation atomically. A provider is unreachable until a durable effect lease exists. Legacy PREPARED/no-effect states are recovered explicitly and fail closed on deadline/drift/expired continuation.

Run creation is resumable from a durable initialization checkpoint, preventing stale idempotency recovery from completing a request while its run remains CREATED/RESOLVING.
