## Final promotion contract
A final V1 promotion requires five receipts from one run, source, runtime environment, deployment config and exact deployment artifact. The central validator—not only the smoke script—enforces each gate's DONE metrics.

The final manifest is Ed25519-signed and must verify against a separately pinned public-key SHA-256. It binds the five receipt digests, source fingerprint, environment fingerprint, deployment fingerprint and artifact digest.

## Strengthened real-provider E2E
The final live E2E must prove all of the following in one synthetic deployment:
1. session/CSRF/idempotent API path reaches approval;
2. real Gmail commits a self-send while qualification deliberately loses the response;
3. ProofOps surfaces `UNKNOWN`;
4. reconciliation finds the original deterministic Message-ID;
5. no resend occurs; physical message count remains exactly one;
6. verified Gmail effect evidence is persisted;
7. an external deployment restart command actually restarts the deployed service;
8. `/ready/providers` becomes green again for the same artifact digest;
9. the pre-restart run is readable and remains `COMPLETED_VERIFIED`;
10. repeating the same renewal produces `DEFERRED` with no second effect;
11. a second synthetic customer whose authoritative Gmail thread says `ACCEPTED` produces `BLOCKED_NEEDS_HUMAN` with zero outbound action.

## Claims intentionally not made
- provider-level exactly-once Gmail delivery
- commercial renewal resolution from outreach alone
- production multi-tenant authorization
- Calendar integration
- live qualification in this execution environment

RC4 remains **offline-qualified** until all five live gates pass without any source change. Any live-discovered source change requires a new RC and requalification.
