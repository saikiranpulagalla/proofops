# ProofOps V0.5.0 Release Report

## Result

V0.5 is unlocked and implemented after a second adversarial audit of V0.4.5.

### Post-hardening defects found and closed before AI unlock

1. Customer-specific completion accepted evidence with no customer identity.
2. Completion evidence was not bound to renewal identity.
3. A caller could back-date `conditions_satisfied_at` while required evidence arrived after the deadline.
4. An expired approval still marked `ACTIVE` could be returned again instead of issuing a fresh approval.

These were fixed before adding the planner.

## V0.5 architecture

`PlanningContext -> model PlanProposal -> strict Pydantic schema -> deterministic PlanValidator -> deterministic PlanCompiler -> audited CompiledPlan`

The model has no tool access and cannot supply recipient, logical key, risk level, provider idempotency key, approval, or execution state.

## Planner rejection classes covered

- schema smuggling / extra fields
- hallucinated evidence references
- missing approval stage
- missing verification stage
- unsafe send ordering
- duplicate send
- invalid dependency graph
- unresolved assumptions driving writes
- DNC / accepted / declined / delayed states
- existing follow-up
- unresolved business conflicts
- unavailable future capabilities
- unreachable GoalContract
- contract/snapshot customer mismatch
- contract/snapshot renewal mismatch

## Observability

Every planner attempt is persisted with:

- run id
- model name
- planning input hash
- raw/parsed proposal
- ACCEPTED / REJECTED / REJECTED_SCHEMA status
- validator issue set

Rejected first outputs are not silently repaired or retried, preserving first-attempt quality metrics.

## External limitation

The build environment has no outbound package/network access, so the real `google-genai` package/API call was not executed here. The production adapter is implemented against the documented Interactions API shape and is tested with an injected client. Real Gemini qualification remains a separate live-integration gate before V0.5 can claim model-quality metrics.
